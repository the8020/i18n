# Purpose

- Own ordinary UUI language configuration and customer translation editing.

# Ownership

- Own this directory and its descendants.

# Local Contracts

- Languages edits enabled languages, system and login defaults, and ordered
  fallback arrays. Default fields provide enabled-language value help.
  Translations opens an English key list for a package/language and saves or
  removes individual overrides. Both use ordinary UUI screens and enforce
  declared permissions at the mutation boundary. Override saves require an
  English source key and matching named variables.
